Очистка текста — обязательный шаг
Сырой текст из PDF часто содержит мусор: колонтитулы, номера страниц, лишние пробелы. Если не чистить — чанки будут грязными и RAG будет работать хуже.
Tesseract нужно установить отдельно — это системная программа, не pip-пакет. 
На Windows: скачать установщик с GitHub, на Linux: sudo apt install tesseract-ocr tesseract-ocr-rus.
